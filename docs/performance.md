# 性能实测与验收记录

2026-10-07，macOS 27.0 ARM64，本机 release 构建。命令见 [开发指南](development.md)，原始数据见 [performance-results.json](performance-results.json)。

## 合成结果集

三列数据（PID、进程名、约 150 字节路径），每组独立运行三次，以下为中位数。旧路径在基准程序中复现改动前的全量复制／排序或整体序列化；并非两份历史可执行文件的整机比较。

| 场景 | 旧路径 | 优化后 |
| --- | ---: | ---: |
| 10,000 行，20 次视图分页准备 | 54.50 ms | 0.58 ms（含一次索引构建） |
| 100,000 行，20 次视图分页准备 | 548.40 ms | 3.96 ms（含一次索引构建） |
| 100,000 行 JSON 导出 | 45.24 ms | 24.87 ms |
| JSON 导出进程峰值 RSS | 109.39 MiB | 30.75 MiB |
| 100,000 行 CSV 导出 | 27.15 ms | 19.76 ms |
| CSV 导出进程峰值 RSS | 93.36 MiB | 30.70 MiB |

视图基准包含搜索、排序和分页行复制，不包含 Ratatui 绘制或终端传输。复用索引后的分页准备无需再次遍历全部行。JSON 流式格式保留相同字段和值，但行内空白更紧凑，耗时收益也包含输出字节数减少；内存指标包含进程中的原始结果集。

快照测量强制落盘，以覆盖超过内存预算的情形：

| 100,000 行快照 | 创建快照（含生成合成输入） | 连续读取 20 页，每页 50 行 |
| --- | ---: | ---: |
| 完整结果 | 29.72 ms | 0.61 ms |
| 部分结果 | 28.37 ms | 0.57 ms |

快照分页不执行分析插件；完整性与诊断跟随快照。此处只测量快照层，端到端 MCP 测试另验证源镜像删除后仍能翻页、部分结果不写成功缓存以及旧 offset 参数的迁移错误。

## Windows 会话复用

样本为已登记的 Server 2019 build 17763 内核 crash。输入符号来源为本地 Windows ISF 目录；交替运行 pslist／modules 共三轮，关闭成功结果缓存。每次独立解析与会话复用的完整结果均逐项相等。

| 指标 | 测量 |
| --- | ---: |
| 镜像准备 | 2.389 s |
| 后续独立解析调用中位数 | 440.81 ms |
| 后续 Session 调用中位数 | 2.61 ms |
| 符号缓存命中 | 5 / 6 次 Session 调用 |

中位数排除各路径首次调用；第一次独立调用还建立页表发现缓存，因此不用于首次启动加速结论。该测试体现符号目录重复解析的成本；具体收益随符号库规模和插件工作量变化。

## 验证范围

- `make check`：格式、Clippy、常规自动测试与 release 构建通过；新增缓存淘汰、流式失败恢复、视图失效、快照分页和 MCP 取消测试。
- Linux 本地真实镜像：4 项验收通过，覆盖 Debian、Kali ARM64、针对性转储和历史导出。
- TUI 本地离线验收：1 项通过，覆盖 Linux／Windows 资源选择到分析。
- Windows：12 项尝试中 7 项通过，包括精确 PDB 转换、Windows 10／11 RAW、Server 2012／2019／2022、用户 minidump 和 Server 2016 triage。
- 其余 5 项（Windows 10 bitmap crash、Server 2003、Server 2008、Server 2012 R2、Windows 7）均在符号准备阶段因缺少精确 ISF 失败，未完成本轮验证；不能计为通过。未下载额外镜像或符号，也未修改验收基线。

真实样本使用现有 `images/feat-windows-plugins/` 路径，通过测试已有的 `ZERO_WINDOWS*_IMAGE` 和 `ZERO_TUI_WINDOWS_IMAGE` 环境变量覆盖默认位置。

## 后续符号兜底验证

增加微软 PDB HTTP 404 → Volatility 官方精确 ISF 兜底后，Server 2003 SP0 x86 的原缺符号项已完成验证：微软返回 404，官方 ZIP 通过三次 HTTPS Range 取得目标条目，ISF 内部名称／GUID／Age 校验通过；随后 `public_server2003_x86` 在 `network: false` 下通过全部已有插件基线。符号及来源清单保存到运行缓存，没有修改验收基线。

测试同时覆盖非 404 不触发兜底、缺失／重复候选、元数据身份不符、ZIP 错误、Range 长度／文件大小变化、请求数量限制、取消和缓存离线复用。
