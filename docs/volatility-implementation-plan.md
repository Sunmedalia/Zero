# Volatility 缺失插件实施计划

目标：补齐固定 Volatility 3 v2.28.2 的 Linux / Windows 插件、参数和输出能力。
完整验收仍遵循 [对齐进度](volatility-parity.md)，不能以入口存在代替功能完成。

## 共享基础先行

现有基础：只读镜像和虚拟地址空间、精确符号、可取消有界遍历、任务链恢复、
部分结果诊断、CLI/TUI/MCP 共用插件描述，以及固定参考版本的逐字段差分工具。
新增插件必须复用这些基础；缺页不填造值，残缺视图不能证明对象不存在。
原 CLI 入口和已有字段保持兼容；新增官方完整入口单独注册。

实施次序：

1. 人工复核 inventory 的候选映射，区分真正缺失与命名不同；保留参数和字段缺口。
2. 补进程身份比较（ProcessSpoofing），复用文件路径与用户内存读取；覆盖名称截断、
   已删除文件、空参数、缺页和取消，并对真实样本逐字段比较。
3. 补模块跨视图、模块提取与 kallsyms，抽取共享模块枚举/符号读取基础。
4. 补物理任务与套接字扫描，抽取结构候选验证、去重与扫描覆盖证据；不能把链表枚举
   当作扫描实现。
5. 补 VMA 正则、调用栈和 framebuffer；明确模式语义、架构与文件输出约束。
6. 补 Windows GUI、系统调用检测、注册表/内存扫描等未覆盖项，并完善已有插件的
   官方参数和完整字段。各平台按依赖推进，不以整个系统单次大改为前提。

每批更新实现与证据，执行相关回归、make check；重大变化 commit + push。
不自动发布 release。参考 Python 仅用于开发测试，不能成为 Zero 运行时依赖。

## 验收记录

每个插件记录：参考源码哈希、入口、参数、全部输出字段、异常语义、正向真实样本、
差分结果和剩余限制。只有这些条件有证据时才提升为 verified。
合成测试证明边界处理；空输出或仅共有字段一致不证明完整对齐。

初始状态：135 个正式插件均未通过完整插件验收；现有 5 项 PsList 全字段差分通过。
后续的能力增长与完整验收数量分别报告。

首批实现：ProcessSpoofing 已接入原生引擎和公共插件描述，新增身份源比较及边界测试；
默认与单 PID 的公开样本差分通过，保留两处真实缺页诊断。下一批推进共享模块视图与
Modxview；多 PID 列表仍作为公共参数基础缺口保留，不因本批单 PID 通过而关闭。

第二批实现：共享 module_kset/list/carving 与分配范围基础已抽取到 modules.rs；
Modxview 实现三个独立视图和 taint 两种输出，默认及 plain-taints 的公开 Debian 样本
差分通过。真实隐藏/tainted 模块和现代内核的边界差分仍需补齐。接下来推进共享模块
ELF/section 读取基础及 ModuleExtract，不跳过前述未验收边界。

第三批实现：共享模块符号/section 读取及原子重建文件发布基础已落地；ModuleExtract
的 x86_64 入口接入 CLI/TUI/MCP。两个公开 Debian 模块的全字段与 ELF 文件内容比较通过，
缺页补零范围显式保留。32 位重建、现代内核真实样本及边界差分仍在缺口中；下一步继续
kallsyms 共用的模块符号读取与核心符号解码，不把本批能力视为完整插件验收。

第四批实现：Kallsyms 的四个来源和来源参数已落地；复用模块符号基础，并加入压缩名称、
地址模式确认、别名尺寸、markers 恢复与来源隔离。Debian 四项全字段差分通过，Kali ARM64
核心枚举另有实际验证。动态 ftrace/BPF、现代配置真实差分及 32 位仍未完成验收。
后续继续补物理任务/套接字扫描的结构验证与覆盖证据，同时保留前述未验收边界。

物理扫描批：先新增共享 `physical` 模块，支持 4/8 字节指针、分块与连续区段边界、
空洞隔离、覆盖统计、取消、命中/输出上限及调用方停止；再实现 `linux.psscan.PsScan`，
物理读取候选字段，父对象通过内核虚拟层读取。合成用例覆盖未链接任务、线程 TGID/TID、
四种退出状态、父对象不可读及连续 LiME 区段。真实默认参数差分和验收记录见对齐进度。
下一批继续复用该基础实现独立 Sockscan 的 file-ops 与 destructor 两个来源，不能以现有
基于文件描述符的 sockstat/netscan 代替物理扫描。其余 Linux/Windows 缺口保持原范围。
