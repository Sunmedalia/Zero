# 原生 TUI 功能对齐检查

| 页面／流程 | 检查内容 | 本次修正 |
| --- | --- | --- |
| 公共导航 | 页面、系统、帮助、命令面板、设置、尺寸限制 | 对齐 H／S／R／V；极小终端仅接受退出；点击已自动识别的系统保留会话 |
| 镜像资源 | 导入、选择、校验、识别绑定、详情、长路径、鼠标 | 名称及目录完整换行；超高条目可见可点击；独立 V 校验复用会话 |
| 本地符号 | 导入、匹配、选择、详情 | 本地匹配先完成镜像准备；保留严格匹配与取消流程 |
| 远程符号 | 保存索引、搜索、总数、精确匹配、下载 | 离线读取已保存索引；全部／匹配独立保存；z 和按钮切换；结构化详情及下载按钮 |
| 分析工作台 | 插件、参数、结果标签、筛选、排序、树、滚动、导出、历史 | 进入后聚焦内容；运行标识位于结果中央；详情缩放时保留行和滚动；覆盖详情不命中底层控件 |

| 设置与主题 | 原字段位置、持久化、主题、自动检测 | 原设置字段顺序；主题左右切换；OSC RGB／RGBA 与 COLORFGBG 明亮色判断 |

对齐回归见 `src/tui/parity_tests.rs`，覆盖上述迁移中发现的差异；原有原生测试继续检查任务取消、陈旧事件隔离、标签、筛选、排序、滚动条、控制字符和宽字符。合成测试之外，使用本地 Linux 镜像及精确符号走真实引擎，并从同一渲染器重新生成文档截图。发布包通过 PTY 检查独立运行与终端恢复。

保留的兼容扩展：F1…F8 等旧功能键别名、缓存 C 别名、设置中的缓存总开关。它们不替代原 TypeScript 的主要快捷键。按后续交互要求，系统选择现仅显示 Linux／Windows，镜像识别在后台完成；选用并匹配成功后自动进入分析页，远程索引搜索框常驻。当前结论是核心页面与操作流程已完成对应检查；未对每种 Windows 镜像、每个插件的取证结果重新验收，数据正确性仍由各引擎测试和样本验收负责。
